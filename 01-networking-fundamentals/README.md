# Module 01 — Networking Fundamentals & Packet-Level Engineering

## Objective

Develop a deep understanding of computer networking from the fundamental bit and byte representation to packet-level communication, protocol behavior, and production troubleshooting.

This module establishes the foundation for advanced routing, switching, data center networking, cloud networking, and AI infrastructure engineering.

## Topics

1. Binary and Hexadecimal Representation
2. Ethernet and MAC Addressing
3. Address Resolution Protocol (ARP)
4. IPv4
5. IPv6
6. Internet Control Message Protocol (ICMP)
7. Transmission Control Protocol (TCP)
8. User Datagram Protocol (UDP)

## Engineering Approach

Every topic will include protocol theory, packet-level analysis, internal working, real-world implementation, Linux behavior, security considerations, troubleshooting, hands-on labs, Wireshark/tcpdump analysis, and interview preparation.
